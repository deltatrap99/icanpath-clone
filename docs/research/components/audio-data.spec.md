Generate offline from the authored demo question bank and lessons using trusted system /usr/bin/say (Samantha or Daniel) + /usr/bin/afconvert. Do not play audio through speakers or use cloud services. The binaries are already present on macOS and English Samantha voice is installed.

Load demo-core.js and demo-assessment.js in a Node VM with localStorage stub (document.addEventListener stub), then D.bank.items filtered by format listening_mcq exposes payload.audio_script for all 3 age bands. Collect learning unit codes via D.makeResult(D.db.sessions['session-demo']).learning_path.units, call D.assessmentRequest('/api/units/'+code) to collect lesson.vocab[].example and lesson.speaking_practice[]. Each text needs one local clip. Strip A:/B: speaker labels from spoken text but preserve original full text as manifest key. Different voice per dialog optional; simple clear English narration acceptable. Voice rate ~150-165 wpm, younger band ~140. Filename sha256(text).slice(0,12)+'.m4a'. AAC m4a format via afconvert (CoreAudio), intermediate AIFF in tmp only.

Output src/audio-manifest.js: window.ICanDemo.audio = {"exact original text":"/audio/hash.m4a",...}; Include all listening and lesson examples/practice, deduplicate. Build one reproducible script that skips already generated clips, with bounded parallelism 2–4. Validate each clip has nonzero duration/bytes using afinfo or ffprobe from /tmp/icanpath-video-tools/bin/ffmpeg (if available) and file existence; report count/size. Root owns html, services, MIME setup, do not edit them. No original site calls or user credentials.
